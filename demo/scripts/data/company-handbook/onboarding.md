# New Employee Onboarding Guide

Welcome to TechCorp! This comprehensive guide will walk you through your first month, ensuring you have everything you need to succeed in your new role.

---

## Pre-Arrival (Before Day 1)

### One Week Before Start Date

**IT Setup** (completed by IT team):
- [ ] Laptop configured with standard software
- [ ] Email account created (firstname.lastname@techcorp.com)
- [ ] Slack account provisioned and added to relevant channels
- [ ] VPN access configured
- [ ] Security credentials (MFA) set up
- [ ] Access badge ordered and printed

**HR Preparation**:
- [ ] Welcome packet emailed with first-day details
- [ ] Benefits enrollment portal activated
- [ ] Direct deposit and tax forms sent for e-signature
- [ ] Parking pass or transit card arranged
- [ ] Desk/workspace assignment confirmed

**Manager Preparation**:
- [ ] 30-60-90 day plan drafted
- [ ] First week schedule created
- [ ] Team introduction meetings scheduled
- [ ] Buddy/mentor assigned
- [ ] Initial projects and goals identified

### What to Bring on Day 1
- [ ] Government-issued ID (for badge photo)
- [ ] Banking information (for direct deposit setup)
- [ ] Signed offer letter and any pre-hire paperwork
- [ ] I-9 documentation (if not completed remotely)
- [ ] Laptop bag (we'll provide the laptop)
- [ ] Water bottle and any personal comfort items
- [ ] An open mind and positive attitude!

---

## Day 1: Welcome and Setup

### Morning (9:00 AM - 12:00 PM)

**9:00 AM - Arrival and Welcome**
- [ ] Check in at reception
- [ ] Meet your manager
- [ ] Badge photo and security access setup
- [ ] Building tour (restrooms, kitchen, meeting rooms, emergency exits)
- [ ] Workspace setup (desk, monitors, peripherals)

**9:30 AM - IT Setup Session**
- [ ] Receive and sign for laptop and equipment
- [ ] First login and password setup
- [ ] Install required applications
- [ ] Configure email and calendar
- [ ] Set up Slack and join essential channels
- [ ] VPN test connection
- [ ] Print setup (if applicable)

**10:30 AM - HR Onboarding**
- [ ] Complete I-9 verification (if pending)
- [ ] Benefits enrollment walkthrough
- [ ] Handbook and policy review
- [ ] Emergency contact information
- [ ] Direct deposit setup
- [ ] Tax withholding forms (W-4)
- [ ] Sign required compliance documents

**11:30 AM - Meet Your Buddy**
- [ ] Introduction to your assigned buddy
- [ ] Buddy explains day-to-day operations
- [ ] Review lunch options and team lunch culture
- [ ] Get answers to "unwritten rules" questions

### Afternoon (12:00 PM - 5:00 PM)

**12:00 PM - Team Lunch**
- [ ] Join team for welcome lunch (company-paid)
- [ ] Meet immediate team members
- [ ] Learn team dynamics and communication styles

**1:30 PM - Role-Specific Onboarding**
- [ ] Review job description and responsibilities with manager
- [ ] Discuss 30-60-90 day objectives
- [ ] Review team charter and current projects
- [ ] Set up recurring 1:1 meetings with manager
- [ ] Identify key stakeholders to meet

**2:30 PM - System Access and Training**
- [ ] Request access to required systems (Jira, GitHub, AWS, etc.)
- [ ] Complete mandatory training modules:
  - [ ] Security Awareness (30 min)
  - [ ] Code of Conduct (20 min)
  - [ ] Data Privacy (25 min)
  - [ ] Harassment Prevention (40 min)
- [ ] Review internal documentation and wikis

**4:00 PM - First Day Wrap-Up**
- [ ] Manager check-in: How was your first day?
- [ ] Set tomorrow's priorities
- [ ] Confirm schedule for rest of week
- [ ] Submit any pending access requests

---

## Week 1: Getting Oriented

### Day 2 (Tuesday)

**Morning**:
- [ ] Attend team standup meeting
- [ ] One-on-one with buddy (30 min)
- [ ] Shadow a colleague in similar role (if applicable)
- [ ] Complete remaining mandatory training:
  - [ ] Company Culture and Values (15 min)
  - [ ] IT Security Best Practices (20 min)

**Afternoon**:
- [ ] Deep dive into team documentation
- [ ] Set up development environment (engineers)
- [ ] Review current sprint/project status
- [ ] Join relevant professional communities/Slack channels
- [ ] Attend any team ceremonies (planning, retro)

**Daily Goals**: Understand team structure and current work

### Day 3 (Wednesday)

**Morning**:
- [ ] Meet with key stakeholders (schedule 30-min intro meetings)
- [ ] Review department goals and KPIs
- [ ] Understand how your role contributes to broader objectives
- [ ] Learn about cross-functional dependencies

**Afternoon**:
- [ ] Complete technical setup (IDEs, repositories, databases)
- [ ] Run through first "hello world" task
- [ ] Review code style guides and best practices
- [ ] Set up local development environment

**Daily Goals**: Complete technical setup and first contribution

### Day 4 (Thursday)

**Morning**:
- [ ] Attend product demo or company all-hands (if scheduled)
- [ ] Meet with product manager to understand roadmap
- [ ] Review customer feedback and user research
- [ ] Understand the "why" behind current priorities

**Afternoon**:
- [ ] Pick up first real task/story (small, well-defined)
- [ ] Work with buddy to understand requirements
- [ ] Start implementation with support
- [ ] Ask questions and document learnings

**Daily Goals**: Begin first meaningful work assignment

### Day 5 (Friday)

**Morning**:
- [ ] Continue work on first task
- [ ] Schedule introductions with extended team members
- [ ] Review first week achievements with manager
- [ ] Complete week 1 survey (HR will send)

**Afternoon**:
- [ ] Finish and submit first task for review
- [ ] Attend team social (if scheduled)
- [ ] Set goals for week 2
- [ ] Weekend prep: What do you need to succeed next week?

**Daily Goals**: Complete first deliverable

### Week 1 Checklist Summary
- [ ] All mandatory training completed
- [ ] All system access granted
- [ ] Met all immediate team members
- [ ] Completed first code/product deliverable
- [ ] Attended all regular team meetings
- [ ] Set up recurring 1:1s with manager

---

## Week 2: Deepening Understanding

### Goals for Week 2
- Build relationships beyond immediate team
- Understand company architecture and systems
- Take on increasingly complex tasks
- Contribute to team discussions

### Key Activities

**Monday**:
- [ ] Meet with 2-3 people from other teams you'll work with
- [ ] Review architecture documentation
- [ ] Attend relevant guild/community meetings (e.g., Frontend Guild)
- [ ] Pick up second task (moderate complexity)

**Tuesday**:
- [ ] Continue building cross-functional relationships
- [ ] Deep dive into technical architecture
- [ ] Review past project post-mortems
- [ ] Understand monitoring and alerting systems

**Wednesday**:
- [ ] Participate actively in team meetings
- [ ] Share perspective as a "fresh eyes" observer
- [ ] Work independently on assigned tasks
- [ ] Document any gaps in onboarding materials

**Thursday**:
- [ ] Meet with skip-level manager (if available)
- [ ] Learn about career growth paths
- [ ] Understand performance review process
- [ ] Attend optional learning sessions

**Friday**:
- [ ] Complete second deliverable
- [ ] Participate in team retrospective
- [ ] Share feedback on onboarding experience
- [ ] Set week 3 goals with manager

### Week 2 Checklist
- [ ] Met all key cross-functional partners
- [ ] Completed 2-3 meaningful work items
- [ ] Attended at least one community/guild meeting
- [ ] Contributed ideas in team discussions
- [ ] Identified growth and learning opportunities

---

## Week 3: Building Independence

### Goals for Week 3
- Work independently with minimal guidance
- Identify areas for process improvement
- Contribute to team planning
- Begin building expertise in specific area

### Key Activities

**Monday**:
- [ ] Take ownership of a larger task or small project
- [ ] Identify one process that could be improved
- [ ] Suggest improvement during team meeting
- [ ] Schedule coffee chats with 2-3 colleagues

**Tuesday**:
- [ ] Work independently on assigned tasks
- [ ] Answer questions from other new hires (pay it forward)
- [ ] Deep dive into area of interest
- [ ] Set up informational interviews with senior team members

**Wednesday**:
- [ ] Participate in sprint/release planning
- [ ] Provide estimates for your work
- [ ] Voice opinions and ask clarifying questions
- [ ] Volunteer for tasks aligned with your interests

**Thursday**:
- [ ] Pair with senior team member on complex task
- [ ] Learn advanced techniques and patterns
- [ ] Review and provide feedback on others' work
- [ ] Document learnings for future new hires

**Friday**:
- [ ] Deliver completed work
- [ ] Self-assessment: What are you confident in? What's still unclear?
- [ ] Share learnings with buddy and manager
- [ ] Set month 1 goals

### Week 3 Checklist
- [ ] Completed independent work with minimal guidance
- [ ] Suggested at least one process improvement
- [ ] Participated in planning meetings
- [ ] Built relationships with senior team members
- [ ] Growing confidence in role-specific skills

---

## Month 1: Full Integration

### Goals for First Month
- Fully integrated into team workflows
- Consistently delivering quality work
- Building area of expertise or specialization
- Contributing to team culture and processes

### Key Milestones

**Week 4 Activities**:
- [ ] Lead a small initiative or task
- [ ] Mentor newer team member (if applicable)
- [ ] Contribute to team documentation
- [ ] Present work or learnings in team meeting
- [ ] Complete 30-day check-in with manager

**30-Day Manager Check-in**:
- [ ] Review 30-60-90 day plan progress
- [ ] Discuss what's going well and what's challenging
- [ ] Adjust goals based on learnings
- [ ] Get feedback on performance
- [ ] Identify additional resources or support needed
- [ ] Set expectations for month 2

### Month 1 Deliverables
- [ ] Completed 5-8 work items or tasks
- [ ] Contributed to at least one team process improvement
- [ ] Built relationships across the organization
- [ ] Demonstrated understanding of team goals and priorities
- [ ] Identified strengths and areas for development

---

## Ongoing Onboarding (Month 2-3)

### Month 2 Focus: Acceleration
- Take on increasingly complex projects
- Build deeper technical or domain expertise
- Start contributing to broader team goals
- Participate in interviews (if interested)

### Month 3 Focus: Optimization
- Achieve full productivity
- Identify specialization or growth path
- Contribute to strategic discussions
- Begin thinking about 6-month goals

### Regular Check-ins
- **Weekly**: Quick sync with buddy
- **Bi-weekly**: 1:1 with manager
- **Monthly**: Formal check-in with manager
- **Quarterly**: 360 feedback and goal setting
